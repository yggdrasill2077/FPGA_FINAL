> 输出：HDMI 1080p60 ｜ 赛题：全国大学生嵌入式芯片与系统设计竞赛·2026 FPGA 赛道【赛题四】

## 1. 系统概述

### 1.1 功能

实时采集 MIPI 摄像头图像，完成**灰度化 → 中值滤波 → 边缘检测 → 形状识别 → HDMI 显示**的全流水线处理，帧率 60 fps、分辨率 1920×1080。

显示为**左右分屏**：

| 区域 | 内容 |
|---|---|
| 左半（0..959） | 灰度图像（1:1 中心裁剪）|
| 右半（960..1919） | 边缘增强图（彩色底图 + 红色边缘叠加）|

### 1.2 与赛题要求对应

| 编号 | 赛题要求 | 本设计实现 |
|---|---|---|
| **B1** | 图像采集 | MIPI CSI-2 硬核 + SC431HAI，1080p60 |
| **B2** | 灰度化（禁除法器） | `rgb888_to_gray`，定点 77/150/29 + 移位加 |
| **B3** | 3×3 Sobel，`G=\|Gx\|+\|Gy\|`，阈值可参数化，2 行 Line Buffer | `sobel_3x3` + `win3x3_2px`；**通路 A** 严格按此实现 |
| **B4** | HDMI ≥640×480@60Hz，分屏，无撕裂 | 1920×1080@60，双 bank 行缓存合成 |
| **B5** | 完整 RTL + 约束 + 演示 | 本仓库 + `ti60f225_oob.xml/.sdc` |
| **A1** | 3×3 中值滤波 | `median3x3_2px`（9 点排序网络）|
| **A2** | 实时阈值调节 | KEY0/KEY3 ±64，长按连发 |
| **A3** | 帧缓存/DDR 回放/冻结 | `frame_buffer_V3`，3 bank，冻结 + 逐帧回放 |
| **A4** | Canny 全流程 | **通路 B**：高斯 → 梯度 → NMS → 双阈值 → 滞后（+ AA 渲染）|
| **A5** | 边缘叠加彩色输出 | 右半彩色底图 + 红边（两级强度）|
| **A6** | 简易目标识别 | 32×18 网格 → 极坐标 128 射线 → DFT 谐波分类（5 类）+ 字母 A–Z |


## 3. 边缘检测算法

### 3.1 双通路设计

| 项 | 通路 A（B3 基础项）| 通路 B（A4 高档项）|
|---|---|---|
| 输入 | 中值灰度（**不做高斯**）| 中值灰度 → 2 级 3×3 高斯 |
| 算子 | **Sobel** `[-1 0 1; -2 0 2; -1 0 1]` | Sobel / **Scharr** `[-3 0 3; -10 0 10; -3 0 3]` 可选 |
| 幅值 | `\|Gx\|+\|Gy\|`（赛题口径）| `max+0.5·min`（C1，逼近欧氏范数）|
| 后处理 | 阈值二值化 | NMS → 双阈值 → 8 连通滞后 → 去斑 → 桥接 → AA |
| 边缘形态 | 2~3 px 厚边 | 1~2 px 细边 + 半强度过渡 |
| 切换 | 编译期 `EDGE_PATH`，或**运行时 KEY2 长按 1 s** | 同左 |

### 3.2 Canny 五步的实现

| 步骤 | 实现 | 参数 |
|---|---|---|
| ① 高斯平滑 | 2 级 3×3 二项式核 `[1 2 1;2 4 2;1 2 1]/16` | σ≈1.06 |
| ② 梯度 | `sobel_3x3`，2 px/clk 并行 | 12 bit 输出 |
| ③ 非极大值抑制 | 4 方向量化 + `>=` 平局规则 | 方向码 0/1/2/3 |
| ④ 双阈值 | `T_hi` 由按键/自动阈值给出；`T_lo = T_hi >> HYST_SHIFT` | `HYST_SHIFT=2` |
| ⑤ 滞后连接 | 8 连通标号 | — |

### 3.3 亚像素抗锯齿渲染（自有增强）

- 利用 NMS 的抛物线亚像素偏移 δ：`δ = 0.5·(G₋−G₊)/(G₋−2G₀+G₊)`（Q4.4）
- 边缘像素输出**全强度**，δ 指向的邻像素输出**半强度**
- 实测（15°/30°/45° 斜边，质心 RMS）：**0.213 px → 0.105 px（−50.7%）**

### 3.4 边缘强度渲染

边缘不再是 0/255 二值，而是**梯度幅值本身**（取高 8 位，下限 160）。沿边缘亮度连续变化，视觉上台阶被抹平。

### 3.5 1px 缺口桥接（连通性增强）

在去斑之后补一点：

```verilog
br = ~c & ((l & r) | (u & d) | (ul & dr) | (ur & dl));
```

- BSDS300 实测：Connectivity **+107%**，FOM +2.8%，边缘密度仅 +23%
- 代价：+20 LUT、0 RAM、0 拍

### 3.6 逐帧直方图自动阈值（光照鲁棒性）

```
每帧：NMS 幅值建 256 bin 直方图（1 RAM10）
帧末：从 bin255 往下累加（只统计非零像素），累计到 3%~8% → 该 bin<<4 即阈值
下一帧：T_hi = 该值（无效时回落到手动值 56）
```

| 实验（40 张 BSDS，亮度缩放 0.4~1.3×）| 固定 T=56 | **自动阈值** |
|---|---|---|
| FOM 均值 | 0.114 | **0.268（+135%）** |
| FOM 波动（极差）| 0.087 | **0.010（8.7 倍改善）** |

## 4. 形状识别

### 4.1 流程

```
中值灰度 → 32×18 网格统计（连通域）→ 每候选框：前景质心
        → 从质心发 128 条射线 → 取最外层前景块 → r(θ)
        → 3 点圆心中值去毛刺 → 归一化 DFT 谐波
        → 分类判决
```

### 4.2 分类判据

| 特征 | 对应类别 |
|---|---|
| A2（二重谐波）| 矩形 / 二重各向异性 |
| A3（三重谐波）| 三角形 |
| A4（四重谐波）| 正方形（含十字）|
| CV（半径变异系数）| 圆 vs 多边形 |
| `min(r)/mean(r)` | 十字 vs 方 |

输出类别码：1=圆、2=方、3=三角、4=十字、5=矩形、0=未知（+ 字母 A–Z）

### 4.3 资源热点（Efinity 层次化报告）

| 模块 | 自身 XLR | 占全设计 |
|---|---|---|
| `u_grid`（`shape_grid_multi_v2`）| **24,263** | **42%** |
| `u_polar` | 8,723 | 15% |
| `u_edge_canny` | 1,706 | 3% |
| `u_shape_multi_osd` | 1,383 | 2% |

> 若需压缩逻辑，优先降低 `GRID_X/GRID_Y`（32×18 → 16×9 预计省 1.2~1.6 万 XLR）。

## 5. 显示合成

| 项 | 实现 |
|---|---|
| 分屏 | 左半灰度 / 右半边缘，行缓存 `comp_gray_mem`/`comp_edge_mem`/`comp_rgb_mem`（4096 深，双 bank）|

| R/B 交换 | `SWAP_RB=1`（CFA 相位与 debayer 打包约定相反）|

## 6. 验证与实测数据

### 6.1 边缘质量（BSDS300，人类标注真值）

| 指标 | 数值 | 说明 |
|---|---|---|
| FOM（Pratt α=1/9）| 0.24~0.27 | 视阈值与配置 |
| ODS / OIS / AP | 0.42 / 0.43 / 0.18 | 自建评测链（容差 0.0075·diag）|
| Connectivity | 0.28（无桥接）→ **0.57（有桥接）** | BSDS 官方口径 |
| 人类标尺（标注互比）| 0.753 | Connectivity 天花板 |
| skimage Canny 参照 | FOM 0.220 / Conn 0.252 | 同量级，链路口径正确 |
| **SSIM** | 0.35~0.93 | ⚠️ **对二值边缘图不适用**（全零图可得 0.95+）|

### 6.2 亚像素 AA

| 角度 | 二值 RMS | AA RMS | 改善 |
|---|---|---|---|
| 15° | 0.259 px | **0.092 px** | 64% |
| 30° | 0.195 px | 0.145 px | 26% |
| 45° | 0 | 0 | 不触发（响应本就对称）|
| 平均 | 0.213 | **0.105** | **50.7%** |

### 6.3 3D 物体（圆台仿真）

| 指标 | 结果 |
|---|---|
| 轮廓召回 | **99.9%** |
| 内部明暗渐变误检 | 41%（可用阈值或 `LAP_GATE_ON` 抑制）|

### 6.4 算子对比（同阈值，BSDS 100 张）

| 算子 | ODS | AP | 45°/0° 单轴响应比 |
|---|---|---|---|
| Sobel | **0.428** | **0.171** | 0.750 |
| Scharr | 0.426 | 0.159 | **0.812（更接近 1）** |

> 结论：**Scharr 在 FOM 中性偏负，仅在方向一致性上更优**；报告不得宣称 Scharr 提升 FOM。

## 10. 按键定义

| 按键 | 功能 |
|---|---|
| KEY0 | 阈值 +64（长按连发）|
| KEY3 | 阈值 −64（长按连发，地板 24）|
